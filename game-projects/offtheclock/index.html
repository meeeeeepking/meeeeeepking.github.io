Off The Clock

Group Size: 3

Role: Tool Designer

About

off the clock is a typing simulator game i made with a group of 2 others for a class durring my first year of college. it was made for a semester long project which had a theme of Do It Yourself. we took that theme as the exclimation "do it yourself" and made a game where you are a lazy guy who need to come up with excuses to not do what people ask him to. this game was made using monogame as that was what the class required us to use.

Gameplay

the gameplay consists of mainly of typing the excuses presented to you for any given task before the person reacher you and makes you do the task. we made 3 levels which increase in dificulty and implement progresivly more parts of writing with the first level only having lower case letters, the second having uper case letters, and the last level including punctuation. our goal with these levels was not only to introduce the game mechanics but to also introduce the main enjoyment of the game, its humor. typing simulators can be boring and we wanted ours to be sily to try and solve that. thus we made the tasks and excuses become ever more rediculous witht he final level essentialy being a short story told through these tasks and excuses.

the game also included a level editor for people to make their own levels. since the game was just a school project this didn't see extensive use but i do think that with enough creativity, some interesting stories and funny scenerios could be created ussing this game.

What I Did

my main work was on the level editor. originaly the level editor was going to be used only by us developers to make the levels but we later decided to implement it into the game. i also implemented the ability to use capital levers and punctuation.

What I Learned

this project taught me the importance of planing for these longer projects and, even more importantly, actualy sticking to those plans. in this project, we each sometimes did things differentaly than was originaly planed without consulting the others leading to confusion when we had to combine our various systems. we were abel to make it work but ona larger project this could have gone much worse so i learned that planing, and transparency about changes to the plan are of utmost importance.
